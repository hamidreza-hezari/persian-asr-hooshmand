# Persian ASR Hooshmand - Frontend Interview Task By Hamidreza Hezari

# Tech Stack
- Next.js 16.2.6
- React 19.2.4
- TypeScript
- Tailwind CSS (v4)
- React Compiler (Babel plugin)
- ESLint & Prettier for code quality

# Folder Organization
- app - Next.js App Router pages and layout
- components - Reusable UI components (nav, sections, ui components)
- assets - Icons and fonts (custom Persian font)
- utils - Utility functions
- constants - Configuration and mock data constants

to get started just run:
 - npm install
 - npm run dev
